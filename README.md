# Travelog
Android 기반 여행 기록 앱 프로젝트

## 사용자가 여행 기록을 저장하고 조회

## 개발 환경
- Kotlin
- Android Studio
- SQLite

## 구현 목표
- Fragment 기반 화면 구성
- RecyclerView 여행 목록
- SQLite CRUD
- 사진 선택 기능
- BottomNavigationView

## 진행 상황

### 기본 구조 완성
- 프로젝트 생성
- GitHub 연동
- BottomNavigation 구현
- HomeFragment / StatsFragment 생성
- Fragment 화면 전환 구현
- 앱 실행 테스트 완료
